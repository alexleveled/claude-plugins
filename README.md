# Claude Code plugins by alexleveled

```
/plugin marketplace add alexleveled/claude-plugins
```

| Plugin | What it does | Install |
|---|---|---|
| [read-aloud](https://github.com/alexleveled/claude-read-aloud) | Reads Claude's last reply aloud with a local voice. VS Code button included. | `/plugin install read-aloud@alexleveled` |
| [done-alerts](https://github.com/alexleveled/claude-done-alerts) | Says out loud when Claude finishes or needs approval, with a one-line summary. Local voice or Fish Audio. | `/plugin install done-alerts@alexleveled` |
